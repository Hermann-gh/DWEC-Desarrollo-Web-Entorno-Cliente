# DWEC — Desarrollo Web en Entorno Cliente

Repositorio destinado a las prácticas, ejercicios y proyectos realizados durante el módulo de **Desarrollo Web en Entorno Cliente (DWEC)** del Grado Superior en Desarrollo de Aplicaciones Web.

## 📚 Contenido

El repositorio está organizado por prácticas y ejercicios.

### Estructura del repositorio

- `practica-01/`
  - `ejercicio-01/`
  - `ejercicio-02/`
  - `ejercicio-03/`
- `practica-02/`
  - `ejercicio-01/`
  - `ejercicio-02/`
- `practica-03/`
  - `...`

Cada práctica contiene sus correspondientes ejercicios de forma independiente.

## 🛠️ Tecnologías

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## 🎯 Objetivo

Desarrollar y practicar los conocimientos relacionados con la programación web del lado del cliente, trabajando con HTML, CSS, JavaScript, DOM, eventos, almacenamiento web y otros conceptos propios del desarrollo frontend.

## 📂 Organización

Cada práctica dispone de su propia carpeta y, dentro de ella, cada ejercicio se encuentra separado en su correspondiente directorio.

Esta organización permite mantener los ejercicios ordenados y facilita su consulta, modificación y seguimiento durante el desarrollo del módulo.
